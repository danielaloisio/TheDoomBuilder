Reject Explorer Mode

This mode lets you view the map's reject data. Available in Doom and Hexen format
Menu path: Mode -> Reject Explorer Mode
Default key: None.

The information about the map's reject data.

Colors (default):

Color Description
Gray there is no line of sight between the highlighted sector and this sector
Light green currently highlighted sector
Dark green there is a bidirectional line of sight between the highlighted sector and this sector
Yellow there is a unidirectional line of sight from the highlighted sector to this sector
Purple there is a unidirectional line of sight from this sector to the highlighted sector

Colors can be customized in the settings (see button in the toolbar)
